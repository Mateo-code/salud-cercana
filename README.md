# salud-cercana

MVP front-end del proyecto Salud cercana (Proyecto de Ingeniería II UNAD).

## Desarrollo local

1. Instala dependencias:
   ```bash
   npm install
   ```
2. Ejecuta el servidor de desarrollo:
   ```bash
   npm run dev
   ```
3. Abre [http://localhost:5173](http://localhost:5173).

La interfaz inicial muestra el mensaje **"Salud cercana MVP"** centrado en la página con estilos de Tailwind CSS.
